# Don’t Touch the Water

Playable build: [godot/](godot/). Import that folder in Godot 4.3+.

Hub setup, linking, and the bridge are in [docs/install.md](../../docs/install.md). Controls and gift actions are in [docs/dont-touch-the-water.md](../../docs/dont-touch-the-water.md).

The React and Three.js files in this folder are the previous browser game. The registry runtime is `desktop`, so the hub shows a link code instead of a play popup. Leave those files until the Godot build has fully taken their place.
