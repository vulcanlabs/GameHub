# Don’t Touch the Water (Godot)

Godot 4.3+ project. Import this folder and press Play.

The window asks for the hub origin, a one-time code from the Don’t Touch the Water page, and a name for this PC. After that, click to capture the mouse.

Install, first live session, and the TikFinity bridge: [docs/install.md](../../../docs/install.md).

Controls, checkpoints, monsters, and F-keys: [docs/dont-touch-the-water.md](../../../docs/dont-touch-the-water.md).

Headless smoke check from the repo root:

```bash
Godot --headless --path games/dont-touch-the-water/godot --quit-after 120 -- --playtest
```
