How to use it

Download GameHub-Launcher.html and Start Game Hub.bat and put them in the same folder.
Double-click Start Game Hub.bat. It opens the launcher like an app window using Edge or Chrome. You can also just open the HTML file in a browser.
Click Don’t Touch the Water, then press Play. The game opens in its own window, so allow pop-ups for the launcher if it asks. Click inside the game to start.
Start TikFinity and connect to your TikTok LIVE. The bottom-left of the launcher shows “TikFinity connected” once it finds TikFinity.
Keep the launcher open while you stream. Each gift runs the action you set for it, and the launcher shows an activity log and your checkpoint.
